# Shifa Care Clinic — portfolio demo

Pure static HTML/CSS/JavaScript, no backend, database, secrets or build step.

## Reuse
Edit `config.js` first: clinic name, phone, WhatsApp number (digits only, with country code), address, directions query, opening hours, services, team placeholders and colors. Update `about.html` and the FAQ copy only with client-approved facts. Replace placeholder contacts before testing. Appointment form opens a pre-filled WhatsApp message; it does not send data to a backend.

All HTML pages include noindex directives; `robots.txt` disallows crawling. Keep these for the fictional demo and discuss indexing before a real launch. Deploy on Cloudflare Pages with no build command and the repository root as output directory.

The clinic and contact details are fictional placeholders. Demo website for portfolio purposes. Not a real clinic.
